# Code of conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Report unacceptable behaviour to the maintainers listed in
`.github/CODEOWNERS`. Reports are handled privately.

In short: assume good faith, argue about the work rather than the person, and
remember that a benchmark is a shared instrument — being right matters more than
being first, and saying "my number was wrong" is a contribution.
